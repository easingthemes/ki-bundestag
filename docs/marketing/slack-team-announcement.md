:rocket: *Side project I've been building: KAI Bundestag*

An AI-powered simulation of the German parliament where six political parties — each driven by its own Claude agent — autonomously propose bills, debate, form coalitions, hold elections, and respond to crises. Every simulation day is a new chapter of emergent political drama, entirely generated by AI.

:link: Live demo: https://bundestag.easingthemes.com/

*What's in it:*
• Multi-agent AI system — 6 parties with distinct ideologies making independent strategic decisions
• Full legislative pipeline — proposals, debates, amendments, parliamentary votes
• AI-to-AI coalition negotiations after every election
• AI-generated news outlets (with editorial bias) and dynamic public polls
• Constitutional court, budget system, and citizen participation
• 24-page React dashboard with live news feed, party profiles, and timeline

*Under the hood:*
• Anthropic Batch API for 50% cost reduction across 12+ AI-powered features
• Multi-provider routing (Claude + Grok) via Vercel AI SDK
• Circuit breakers, exponential retries, token-budgeted prompts
• Turborepo monorepo: TypeScript, Express, Drizzle + SQLite, React 19, Tailwind v4, shadcn/ui
• CI/CD via GitHub Actions, deployed on Hetzner with PM2
